# ServiceNow Service Desk Practice Project

## Project Overview

This project documents my hands-on practice using a ServiceNow Personal Developer Instance. The objective was to develop practical familiarity with common Service Desk activities, including incident handling, user administration, documentation and multi-factor authentication.

The project was completed in a personal training environment using fictional users and scenarios. No organisational or customer data is included.

## Activities Completed

### Incident Management

- Created and categorised a sample Wi-Fi connectivity incident.
- Selected the caller, contact channel, category, impact and urgency.
- Reviewed the automatically calculated priority.
- Assigned the incident to a Service Desk group and analyst.
- Progressed the incident from New to In Progress and Resolved.
- Recorded troubleshooting actions using internal Work notes.
- Provided user-facing updates through Customer visible comments.
- Added a resolution code and detailed resolution notes.

### User Administration

- Created and activated a test user account.
- Set a temporary test password.
- Reviewed user roles and group-related information.
- Modified the user form layout to display the MFA setting.

### Multi-Factor Authentication

- Enabled MFA for an individual test user.
- Enrolled the user through an authenticator application.
- Tested login using a password and time-based verification code.
- Reviewed the difference between ServiceNow-managed MFA and workplace identity-provider MFA.

## Sample Incident

**Issue:** A user was unable to connect a company laptop to the office Wi-Fi.

**Initial assessment:** The issue affected one user, while other employees remained connected.

**Troubleshooting performed:**

1. Confirmed that Wi-Fi was enabled.
2. Confirmed that airplane mode was disabled.
3. Checked that the correct wireless network was selected.
4. Removed and recreated the saved wireless profile.
5. Reconnected the laptop using the approved authentication method.
6. Confirmed internet and Microsoft Teams access with the user.

**Outcome:** The connection was restored and the incident was resolved with troubleshooting actions and resolution details documented in ServiceNow.

## Skills Demonstrated

- ServiceNow incident logging and lifecycle management
- Incident categorisation and prioritisation
- Assignment groups and analyst allocation
- Internal work notes and customer communication
- Structured troubleshooting documentation
